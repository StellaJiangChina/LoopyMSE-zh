# LoopyMSE-zh
Casio Loopy模拟器。目前仍在开发中，已可运行商业游戏并支持音效。

特性：
- 支持运行所有商业游戏，包括《Magical Shop》。
- 支持声音。
- 提供HLE打印机。
- 支持PCM扩展音频HLE。
- 支持控制器操作。
- 兼容Mac、Windows和Linux平台。

待添加特性:
- 鼠标模拟

## 发行版

[Github Actions](../../actions/) 为Linux、Windows、MacOS Intel和MacOS ARM64提供最新的编译发行版本。
